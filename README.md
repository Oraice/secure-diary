# 安全日记本・Secure Diary

本地优先、端到端加密的私人日记本。**你的日记，只有你能打开。**

- 数据在**你自己的设备上加密后**才存储与同步
- 服务器、云服务商、甚至拿到你手机的人，都读不到一个字
- 无账号、无追踪、纯本地运行，可随时导出加密备份
- 原生 App 级过渡动效：视图推入/返回滑动（旧视图淡出后再滑入，无抖动）、卡片错峰浮现、保存反馈动画
- 常用标签一键选择（预设按钮 + 自定义标签），自动锁定下拉框改为自绘选项
- 自动备份提醒：超过 7 天未导出加密备份时在日记列表顶部提示（可稍后，1 天内不重复打扰）
- 自动同步（可开关）：解锁后每 30 分钟自动同步一次，回到本页面时也会检查，失败静默不打扰
- 月度回顾：心情日历（点击日期回看当日）、篇数/记录天数/最长连续/字数统计、心情分布
- 空壳不入库：一条字都没有的新日记不会自动生成；解锁时自动清理历史空白记录，列表与统计只计有内容的日记
- 图案快捷解锁：本机绘制图案快速解锁，无需每次输入主密码（便捷层，不替代主密码）
- 恢复密钥：忘记主密码时，用创建时保存的恢复密钥解锁本机（本地生成、只显示一次，不经过任何服务器）

***

## 安全架构

| 环节    | 方案                              |
| ----- | ------------------------------- |
| 内容加密  | **AES-256-GCM**（带完整性认证，防篡改）     |
| 主密码派生 | **PBKDF2-SHA256**，60 万次迭代，抗暴力破解 |
| 密钥驻留  | 只在解锁期间存在于内存，锁定即清除，从不落盘          |
| 条目绑定  | 每条密文绑定条目 ID（AAD），防止密文互换         |
| 多设备同步 | 端到端加密（零知识），GitHub 私有仓库只存密文      |
| 备份    | 导出加密 `.vault` 文件，可存网盘 / U 盘     |

工作原理：主密码 → 60 万次密钥派生 → 数据密钥（内存中）→ 每条日记用随机 IV 的 AES-256-GCM 加密 → 密文存入本地 IndexedDB 与云端仓库。**没有主密码，任何数据都无法解密。**

## 快速开始

### 方式 A：直接打开（最简单）

双击 `index.html`，用 Chrome / Edge 打开即可使用。数据全部保存在本机浏览器中。

（此方式下 PWA 安装与离线缓存不可用，需要多设备同步请用方式 C。）

### 方式 B：本地小服务器（桌面推荐）

Windows 在应用目录下运行：

```
python -m http.server 8123
```

然后浏览器访问 `http://127.0.0.1:8123`。此方式支持 PWA 安装与离线使用。

（或者直接把本文件夹放到任意静态站点目录。）

### 方式 C：部署到免费静态托管（推荐，手机也能用）

把本文件夹上传到 **GitHub Pages** / **Netlify** / **Cloudflare Pages** 任一平台即可，免费、全 HTTPS。

部署后任何设备浏览器访问该网址，iPhone 也可以安装到主屏幕。

## 恢复密钥（忘记主密码时的本机找回凭证）

创建日记本时会生成一串随机恢复密钥（只显示一次）。忘记主密码时，在锁屏点「忘记主密码？用恢复密钥解锁」输入它即可进入，随后建议尽快修改主密码。

使用须知（请务必理解）：

- 恢复密钥**本地生成、只显示一次**，本应用不存储明文、不同步、不进备份——它和主密码一样，丢了就没有任何找回通道
- 它只解锁**本机**日记本；换了设备/清除浏览器数据后恢复密钥随之失效（恢复密钥与加密备份互相独立，请都妥善保存）
- **修改主密码后恢复密钥自动失效**，需在设置 → 安全 → 恢复密钥 重新生成
- 也可在设置页随时「重新生成」（旧密钥立即作废）
- 备份导入时同样支持用恢复密钥解密（忘密码但保留了旧备份的场景）

## 图案快捷解锁

觉得每次输入主密码麻烦？可在 设置 → 安全 → 图案快捷解锁 开启：

- **开启方式**：点「设置」，连续绘制两遍同一图案（至少连接 4 个点）
- **使用方式**：锁屏时默认显示九宫格，绘制正确图案即可进入；也可点「使用主密码解锁」随时切回密码
- **更改 / 关闭**：设置页可随时更改图案或关闭快捷解锁

安全边界（务必了解）：

- 图案解锁是**便捷层**，不是安全层。图案只存在**本机浏览器**里，不参与备份、不同步到云端
- **主密码仍是最终保障**：图案防的是"随手翻看"级别，不是恶意攻击。图案连续错误 5 次与密码共享同一限流（指数退避，最长锁 1 小时）
- **修改主密码后，快捷解锁会自动重置**，需要重新设置图案
- 换了新设备 / 清除浏览器数据后，快捷解锁不迁移，重新设置即可

## 开启多设备同步（GitHub 私有仓库）

整个流程约 3 分钟，免费。同步数据**先加密后上传**，GitHub 服务器上只有密文。

### 第 1 步：创建私有仓库

1. 登录 GitHub，点右上角「+」→ New repository
2. 仓库名如 `secure-diary`，**必须选择 Private**
3. 不要勾选任何初始化选项，点 Create

### 第 2 步：创建访问令牌（Fine-grained PAT）

1. GitHub 右上角头像 → Settings → Developer settings → **Personal access tokens** → **Fine-grained tokens** → Generate new token
2. Token name 随意；Expiration 建议 90 天或自定义
3. Repository access 选择 **Only select repositories** → 勾选刚创建的 `secure-diary`
4. Permissions → **Repository permissions** → **Contents** 设为 **Read and write**（其余全部保持 No access）
5. 点 Generate token，**复制**生成的 `github_pat_...`（只显示一次）

### 第 3 步：在应用里配置

1. 打开应用 → 设置 → 多设备同步
2. 填写 GitHub 用户名、仓库名、令牌
3. 点「保存并连接」→ 自动开始首次加密同步

之后每次解锁自动同步；也可手动点「立即同步」。

> 令牌仅保存在本机浏览器中，只用于直接访问 GitHub API。泄露了令牌别人也只能看到密文，但为保险起见，泄露后请立即到 GitHub 吊销并重新生成。

## 备份建议

- **导出加密备份**：设置 → 备份 → 导出，生成 `secure-diary-backup-*.vault` 文件，建议定期存到网盘 / U 盘
- **多设备双保险**：开启 GitHub 同步后，云端即有一份密文副本
- 备份文件是加密的，导入时需要输入**创建时的主密码**

***

## 安全边界（请知悉）

- **主密码不可找回**。忘记密码 = 日记永久无法解密，没有任何找回通道
- 加密防的是：设备丢失 / 被盗、云端服务器被攻破、数据被拦截
- 加密防不了：设备已被恶意软件入侵、别人在你解锁后使用设备（如被当面解锁）
- 请使用足够强且记得住的主密码（混合大小写、数字、符号）
